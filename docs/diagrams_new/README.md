# 다이어그램 (최신)

지금 코드 · 명세 기준으로 다시 그린 구성도 · 시퀀스 다이어그램 (2026-11-25 기준). `docs/diagrams/`는 10/27 초기 설계본이라 그대로 두고, 바뀐 흐름은 여기 새로 그렸다.

- 형식: draw.io (`.drawio`). 한 파일에 여러 페이지가 있는 것은 아래 표에 페이지 이름을 적었다
- 근거 문서: [api/README.md](../api/README.md) · [api/user.md](../api/user.md) · [api/admin.md](../api/admin.md) · [prediction.md](../prediction.md) · [app/README.md](../app/README.md)
- 공통 생략: Nginx 프록시(`/api`)는 시퀀스 다이어그램에서 뺐다 (구성도에만 있음)

## 초기본(`docs/diagrams/`)과 달라진 점

| 흐름 | 초기본 | 지금 |
|---|---|---|
| 공통 | 사용자 웹(React)만, API 경로 임시(`/api/stations?region=mapo` 등) | 앱(RN) · 웹이 `packages/core`를 같이 씀, 경로 `/api/v1/...`, 마포 66곳 + 서울 약 1,560곳 |
| 수집 · 예측 | 없음 | 새로 그림 — collector 5분 수집(마포 · 전국 휴게소 · 서울) → producer 체크포인트 → ml 예측 → Redis `pred:v2` · `pred:raw:v1`, 04:00 기준선, Discord 알림 |
| 지도 조회 | Redis에 목록 5분 캐시 | api 워커 메모리 30초 캐시 + gzip 압축본 (#211), 예측 · 기준선은 Redis에서 읽기 |
| 상세 조회 | 요청 때 api가 ml `POST /predict` 호출 · 5분 캐시 | ml 호출 없음 — collector가 미리 계산한 `pred:v2`를 읽고, 없으면 기준선 → `null` (`AI-07`). 예측 시점 15 · 30분, 서울은 예측 없음 |
| 검색 · 필터 | 필터는 지금 기준만 | 검색 · 추천은 고른 시점 기준 혼잡 제외, 지도에 추천 Top 3 마커는 필터와 상관없이 표시. 상태 이상 충전기 화면(#213) 추가 |
| 추천 | 없음 (상세 끝에 "별도 다이어그램") | 새로 그림 — 호출 기준(처음 · 5분 · 500m + 2분 · 필터 적용), 마포구 밖 422, 카카오 다중 목적지 → 자동차 길찾기 → 직선거리 추정, AI 패키지 채점 함수로 순위 |
| 길찾기 | 없음 | 새로 그림 — 캐시 없음, 하루 예산 2,000 · IP당 분당 10회, 지도 앱 딥링크 |
| 휴게소 | `GET /api/rest-areas` · 휴게소 4곳 | 앱: 전국 휴게소 15 · 16번 API, 노선별 · 지역별 · 검색. 웹은 아직 천안 4곳(5 · 6번) |
| 운영자 로그인 | (11/15에 맞춤) | 경로 `/api/v1/...`로 통일, 만료 시 `/auth/me` 다시 확인 → 로그인 화면 |
| 운영자 대시보드 | 한 화면 · 이용률만 Redis 5분 캐시 | 세 화면(운영 현황 · 상태 이상 충전기 · 데이터 수집), 이용률은 끝난 날 · 시간대별 Redis 집계(#210), 결측 대체 건수는 빼기로 함(11/25) |
