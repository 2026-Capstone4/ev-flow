# 스토어 업데이트 노트

App Store "이번 버전에서 업데이트된 사항"과 Play Console "출시 노트"를 쓰는 방식, 그리고 버전마다 실제로 낸 글을 적어 둔다.
새 버전을 올릴 때마다 아래 [버전별 기록](#버전별-기록) 맨 위에 하나씩 더한다.

## 쓰는 방식

### 1. 범위 정하기

- 지난번 **출시된 빌드**를 만든 커밋부터 지금까지 바뀐 것을 본다. 심사에서 떨어진 빌드나 올리기만 한 빌드는 기준이 아니다
- 앱에 들어간 변경만 뽑는다

```bash
git log --no-merges --format="%s" <지난 출시 빌드 커밋>..HEAD -- mobile packages/core
```

### 2. 고르기

| 넣음 | 뺌 |
|---|---|
| 사용자가 보거나 느끼는 기능 · 화면 · 문구 변경 | 빌드 설정 · 서명 · 빌드 번호 · 언어 선언 |
| 체감되는 속도 개선 (예: 탭을 열면 목록이 바로 보임) | 웹 전용 변경 (`feat(web)` · `feat(fe)`) |
| 사용자가 겪었을 문제를 고친 것 | 다른 플랫폼 전용 수정 (App Store 노트엔 Android 전용, Play 노트엔 iOS 전용을 뺌) |
| | 사용자가 알아채기 어려운 디자인 미세 조정 → 하나로 묶음 ("배치를 보기 편하게 맞췄어요") |

- 서버 배포가 있어야 동작하는 기능은 **실서버 배포를 확인한 뒤에만** 넣는다 (예: 마포구 밖 추천은 백엔드 #249 배포가 필요)

### 3. 쓰기

- 해요체, 사용자 말로 쓴다. PR 제목의 기술 용어(줌 · 마스크 · 시트 · 탭 상한 등)는 쓰지 않는다
- 묶음 순서: **새로워진 점 → 더 편해진 점 → 고친 점**. 묶음 안에서는 체감이 큰 것부터
  - App Store 업데이트 목록에선 처음 2~3줄만 보이고 나머지는 "더 보기"로 접힘
- 줄마다 `- `로 시작하고 한 줄에 하나만
- 서비스 이름은 "EV Flow"

### 4. 스토어별 차이

| | App Store | Play Console |
|---|---|---|
| 입력 위치 | App Store Connect → 버전 페이지 → 이번 버전에서 업데이트된 사항 | 테스트 및 출시 → 트랙 → 새 버전 만들기 → 출시 노트 |
| 길이 | 4,000자 | 언어당 500자 → App Store 글을 줄여서 씀 |
| 형식 | 글 그대로 | `<ko-KR>` … `</ko-KR>` 태그 안에 씀 |
| 첫 출시(1.0.0) | 칸이 없음 (업데이트부터) | 써도 됨 |

- Play Console 출시명은 자동으로 채워지는 `versionCode (versionName)` 그대로 둔다 (예: `2 (1.0.1)`). 사용자에겐 안 보임

## 버전별 기록

### 1.0.1 — iOS (6) · Android versionCode 2 (2026-11-27)

범위: 1.0.0 (5) 빌드 커밋 `aa60161` 이후 (#213 ~ #274). PR #273

App Store

```text
EV Flow 1.0.1 업데이트

새로워진 점
- 마포구 밖에서도 지금 출발 기준으로 충전소를 추천해 드려요
- 지도를 제주도 · 울릉도 · 독도까지 대한민국 전체로 넓게 볼 수 있어요
- 돌아간 지도를 북쪽이 위로 오게 되돌리는 나침반 버튼이 생겼어요
- 첫 방문 안내가 지도 마커 · 추천 패널 · 검색창 · 휴게소 탭을 직접 짚어 알려 줘요
- 새 버전이 나오면 앱에서 알려 드려요
- 앱 아이콘과 시작 화면을 새로 다듬었어요

더 편해진 점
- 위치 권한이 꺼져 있으면 현재 위치 버튼에서 바로 설정을 열 수 있어요
- 상태 이상 충전기 화면이 서울 전체로 시작하고, 맨 위로 버튼이 생겼어요
- 휴게소 탭을 열면 목록이 바로 보여요
- 추천 문구를 더 읽기 쉽게 바꿨어요 (예: '거의 안 기다려요', '덜 붐벼요')
- 글자 크기와 추천 카드 배치를 보기 편하게 맞췄어요

고친 점
- 글자를 크게 설정한 기기에서 화면이 깨지던 문제를 고쳤어요
- 키보드가 떠 있을 때 화면을 넘기면 키보드가 먼저 내려가요
```

Play Console (비공개 테스트, 1.0.0 이후 변경 중 큰 것만)

```text
<ko-KR>
- 지도를 대한민국 전체로 넓게 볼 수 있어요
- 첫 방문 안내가 실제 화면을 짚어 주도록 바뀌었어요
- 새 버전이 나오면 알려 드려요
- 앱 아이콘이 바뀌었어요
</ko-KR>
```
